# RITMO COMERCIAL Y VENTAS SOSTENIBLES - SAGA FALABELLA

## PROPÓSITO
Lograr una venta efectiva y perdurable en el tiempo, donde la calidad de la venta sea el factor de mayor peso.

## BENEFICIOS
- Cliente: Buena experiencia
- Negocio: Resultado sostenible

## BASE METODOLÓGICA
Ventas Sostenibles

## LOS 7 MOMENTOS DE VERDAD (Secuencia obligatoria)

1. ABORDAJE
2. CONTACTO INICIAL
3. INDAGACIÓN Y PERFILAMIENTO
4. ASESORÍA
5. NEGOCIACIÓN
6. CIERRE
7. SEGUIMIENTO

Secuencia completa: Abordaje → Contacto inicial → Indagación → Asesoría → Negociación → Cierre → Seguimiento

## CAPAS DEL MODELO DE ACTUACIÓN COMERCIAL

### Capa 1: Momentos de verdad
Pauta de los momentos comerciales con el cliente

### Capa 2: Atributos
Cómo el cliente espera que sea el asesor

### Capa 3: Comportamientos
Lo que se espera que se haga en la interacción con el cliente

### Capa 4: Habilidades
Lo que el asesor debe saber hacer para lograr resultados

## CAPACIDADES Y SOPORTES

- Mindset escénico: Base mental y actitudinal
- Rapport: Sintonía con el cliente
- Argumentación: Presentar valor y sostener la conversación
- Manejo de objeciones: Responder dudas y resistencias
- Cierre: Concretar el avance comercial
- Conocimiento del producto: Elemento transversal

## ETAPAS DE ENTRENAMIENTO

### Etapa 1: Preparación
- Mindset escénico
- Conocimiento del producto

### Etapa 2: Apertura comercial
- Abordaje
- Contacto inicial
- Rapport

### Etapa 3: Diagnóstico
- Indagación y perfilamiento

### Etapa 4: Propuesta de valor
- Asesoría
- Argumentación

### Etapa 5: Conversación de decisión
- Negociación
- Manejo de objeciones
- Cierre

### Etapa 6: Sostenibilidad comercial
- Seguimiento

## QUÉ EXIGE ESTE RITMO COMERCIAL DEL ASESOR

- Comprender cada etapa del proceso comercial
- Actuar según lo que el cliente espera
- Ejecutar comportamientos observables en cada interacción
- Dominar las habilidades necesarias
- Sostener la conversación con conocimiento real del producto

## INSTRUCCIÓN PARA EL AGENTE

Cuando un usuario pregunte sobre el ritmo comercial:
1. Identifica en qué momento de los 7 se encuentra
2. Explica qué hacer en esa etapa específica
3. Si el cliente tiene duda, identifica si es objeción o falta de claridad en la etapa actual
4. Siempre orienta al siguiente paso concreto según la secuencia
