# PRODUCTO VIDA CON DEVOLUCIÓN - TARIFARIO - PACÍFICO / SAGA FALABELLA

## QUÉ ES
Estructura financiera completa del producto Vida con Devolución. Define cuánto paga el cliente, cuánto recibe al final, cómo escala el precio con la edad y cómo se construye el retorno.

## ESTRUCTURA DEL PRODUCTO

### Variables principales
- Edad del cliente
- Años de vigencia
- Suma asegurada
- % de devolución

### Planes disponibles

### Devolución
100%, 120%, hasta 200%

A mayor plazo: mayor devolución, mayor retorno.

### Plan 7 años

### Plan 20 años

Cliente decide: liquidez vs rentabilidad.

## COMPONENTE DE PROTECCIÓN
Suma asegurada: S/50,000 o S/100,000

Mientras ahorra, está protegido.

Diferencia:
- Ahorro tradicional: no protege
- Este producto: protege + devuelve
