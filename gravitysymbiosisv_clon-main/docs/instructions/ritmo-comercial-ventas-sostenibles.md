# Sistema De Conocimiento Comercial Para Seguros Falabella

# Objetivo Principal

Convertir el playbook comercial de Seguros Falabella en una base de conocimiento accionable para vendedores.

Este documento no debe usarse como un resumen.

Debe usarse como una herramienta de entrenamiento, consulta, argumentación y cierre.

El vendedor debe poder entrar a una conversación con el cliente y saber exactamente qué preguntar, qué producto recomendar, cómo explicar el valor, cómo comparar opciones, cómo manejar objeciones y cómo cerrar sin sonar agresivo.

# Cómo Usar Este Conocimiento

# Uso 1 Entrenamiento Del Vendedor

El vendedor debe estudiar este contenido para dominar el portafolio completo.

Debe entender qué problema resuelve cada seguro.

Debe saber explicar cada producto en palabras simples.

Debe saber traducir características técnicas en beneficios reales.

Debe saber identificar cuándo ofrecer cada producto.

Debe saber defender el precio desde el riesgo que evita.

# Uso 2 Guía Durante La Venta

Este conocimiento sirve como mapa para conducir la conversación.

Primero se diagnostica.

Luego se educa.

Después se compara.

Luego se muestra valor.

Finalmente se cierra.

El vendedor no debe saltar directo al precio.

El precio solo tiene sentido después de que el cliente entiende el riesgo, la cobertura y el impacto económico de no estar protegido.

# Uso 3 Manejo De Objeciones

Cada objeción debe verse como información.

Si el cliente dice que es caro, está mirando la cuota.

Si el cliente dice que ya tiene seguro, cree que está cubierto.

Si el cliente dice que lo pensará, puede estar escondiendo una duda real.

Si el cliente dice que es joven, no entiende que el seguro se compra antes de necesitarlo.

# Principio Comercial Central

El cliente no compra seguros.

El cliente compra protección económica, tranquilidad, continuidad familiar, respaldo ante emergencias y reducción de riesgo financiero.

El vendedor no debe vender pólizas.

Debe vender escenarios protegidos.

# El Ritmo Comercial De Ventas Sostenibles

# Paso 1 Abordaje

# Qué Es

El abordaje es la apertura de la conversación.

No es el momento de empujar producto.

Es el momento de generar disposición, confianza y control.

# Objetivo

Abrir la conversación con seguridad.

Instalar una postura profesional.

Mostrar que el vendedor no está improvisando.

Crear espacio para una venta consultiva.

# Cómo Debe Pensar El Vendedor

No estoy aquí para vender rápido.

Estoy aquí para detectar riesgo, ordenar la decisión y ayudar al cliente a protegerse bien.

# Preguntas De Abordaje

¿Qué tipo de protección estás buscando hoy?

¿Esto lo estás viendo por prevención, renovación o una necesidad puntual?

¿Buscas una opción básica o una cobertura más completa?

¿Hoy quieres proteger salud, auto, ingresos, familia o patrimonio?

# Frase De Uso Comercial

Para recomendarte bien, primero quiero entender qué necesitas proteger realmente, porque no todos los seguros cumplen la misma función.

# Paso 2 Contacto Inicial

# Qué Es

El contacto inicial crea sintonía.

El cliente debe sentir que está hablando con un asesor y no con alguien que solo quiere vender.

# Objetivo

Generar confianza.

Reducir resistencia.

Entender experiencia previa.

Detectar sensibilidad a precio, cobertura, respaldo o atención.

# Preguntas De Contacto

¿Has tenido antes algún seguro?

¿Qué experiencia tuviste?

¿Qué valoras más en un seguro?

¿Precio, cobertura, respaldo, atención o facilidad de uso?

¿Te ha pasado antes que pensabas estar cubierto y después apareció una exclusión o un copago?

# Frase De Uso Comercial

Perfecto, antes de mostrarte opciones prefiero entender tu experiencia anterior, porque muchas personas tienen seguros, pero no siempre saben qué cubren realmente.

# Paso 3 Indagación

# Qué Es

La indagación permite descubrir la necesidad real.

El vendedor debe escuchar antes de recomendar.

No debe presentar productos sin entender riesgo, urgencia, presupuesto y contexto.

# Objetivo

Identificar el riesgo principal.

Identificar presupuesto.

Identificar urgencia.

Identificar producto correcto.

Anticipar objeciones futuras.

# Preguntas De Indagación

¿Qué quieres proteger principalmente?

¿A ti, a tu familia, tu auto, tus ingresos o tus padres?

¿Tienes alguna cobertura activa?

¿Conoces los topes, copagos o exclusiones de esa cobertura?

¿Qué pasaría si mañana ocurre una emergencia médica, un accidente o una hospitalización?

¿Cuánto te afectaría económicamente cubrir ese gasto sin seguro?

# Clave Comercial

La pregunta correcta hace que el cliente descubra el riesgo por sí mismo.

Cuando el cliente verbaliza el riesgo, el cierre se vuelve más natural.

# Paso 4 Asesoría

# Qué Es

La asesoría transforma información en valor.

No basta con decir qué incluye el producto.

El vendedor debe explicar cómo funciona, cuándo se usa, qué riesgo evita y qué impacto económico puede reducir.

# Objetivo

Educar al cliente.

Traducir características en beneficios.

Mostrar impacto real.

Preparar el cierre.

# Fórmula De Explicación

Característica.

Función.

Beneficio.

Impacto económico.

Consecuencia de no tenerlo.

# Ejemplo

Suma asegurada significa respaldo económico.

Respaldo económico significa que el cliente no depende solo de sus ahorros.

No depender solo de sus ahorros significa proteger patrimonio.

Proteger patrimonio significa evitar que una emergencia destruya años de esfuerzo financiero.

# Paso 5 Negociación

# Qué Es

La negociación aparece cuando el cliente duda, compara, posterga o resiste el precio.

La objeción no debe tomarse como rechazo.

Debe tomarse como información.

# Objetivo

Validar.

Reencuadrar.

Comparar costo versus riesgo.

Recuperar control.

Llevar al cliente a una decisión.

# Regla De Oro

Nunca niegues la objeción.

Primero valida.

Luego pregunta.

Después reencuadra.

Finalmente cierra.

# Fórmula

Entiendo lo que me dices.

Tiene sentido que lo mires así.

Déjame hacerte una pregunta.

Si mañana ocurre el evento que este seguro cubre, ¿qué sería más caro, pagar una cuota controlada o asumir todo el gasto de golpe?

# Paso 6 Cierre

# Qué Es

El cierre es la formalización de una decisión responsable.

No es presión.

Es ayudar al cliente a tomar acción antes de que el riesgo aparezca.

# Objetivo

Activar cobertura.

Confirmar decisión.

Reducir postergación.

Proteger al cliente desde hoy.

# Frase De Cierre

Con lo que me comentas, esta cobertura hace sentido porque protege exactamente el riesgo que hoy podrías enfrentar. Activémosla ahora para que no quede pendiente.

# Paso 7 Seguimiento

# Qué Es

El seguimiento es parte de la venta sostenible.

La venta no termina cuando el cliente firma.

Termina cuando el cliente entiende, confía, usa correctamente su cobertura y puede renovar o referir.

# Objetivo

Confirmar comprensión.

Resolver dudas.

Aumentar confianza.

Generar renovación.

Generar referidos.

# Frase De Seguimiento

Te escribo para confirmar que quedó clara tu cobertura, tus beneficios y los puntos importantes como carencia, espera y derecho de arrepentimiento. La idea es que tengas todo transparente desde el primer día.

# Fórmula Central

Calidad de venta más excelente experiencia del cliente igual a resultado perdurable.

El cliente no necesariamente está rechazando.

Está diciendo que cree estar cubierto.

El vendedor debe validar y luego mostrar posibles vacíos.

No debe atacar la EPS.

Debe complementar.

Complementariedad.

Eso es excelente, porque significa que ya tienes una base de protección. La pregunta importante es si esa cobertura cubre el 100% en escenarios críticos, si tiene topes, copagos o exclusiones. Muchas veces el problema no es tener o no tener seguro, sino descubrir demasiado tarde que había un vacío. Justamente este producto puede ayudarte a cerrar ese espacio para que no tengas que tocar tus ahorros.

Si ya estás completamente cubierto, perfecto. Pero si existe un vacío, lo inteligente es cerrarlo antes de necesitarlo.

# Objeción Es Muy Caro O No Tengo Dinero

# Qué Significa Realmente

El cliente está mirando la cuota.

El vendedor debe hacer que mire el riesgo.

La comparación correcta no es seguro versus no seguro.

La comparación correcta es cuota mensual controlada versus gasto grande inesperado.

# Reencuadre

Costo versus riesgo.

# Respuesta Ideal

Entiendo que el presupuesto es importante. Pero déjame ponerlo en perspectiva. Una cuota mensual es un gasto controlado. Una emergencia médica, un accidente o un tratamiento complejo puede significar decenas de miles de soles de golpe. Este seguro no busca quitarte dinero, busca evitar que un evento inesperado destruya tus ahorros o afecte a tu familia.

# Pregunta De Control

Si mañana ocurre una emergencia, ¿prefieres usar tus ahorros o una cobertura activada?

# Cierre Sugerido

Si el objetivo es proteger tus ahorros, lo más responsable es dejar la cobertura activa hoy.

# Objeción Soy Joven O No Lo Necesito Ahora

# Qué Significa Realmente

El cliente cree que el seguro se compra cuando aparece la necesidad.

El vendedor debe educar que el seguro se compra antes de necesitarlo.

Estar sano es una ventaja comercial y de asegurabilidad.

# Reencuadre

Prevención oportuna.

# Respuesta Ideal

Justamente porque hoy estás bien, este es el mejor momento para contratarlo. Los seguros funcionan cuando se toman antes del problema, no después. Cuando aparecen síntomas, diagnósticos o antecedentes, puede que la cobertura cambie o ya no sea posible contratar. Hoy tienes la salud de tu lado, y eso es una ventaja.

# Pregunta De Control

Si hoy puedes asegurarte estando sano, ¿qué ganas esperando a que exista un problema?

# Cierre Sugerido

Aprovechemos que hoy estás bien para dejar tu cobertura activa.

Sentido de urgencia.

# Respuesta Ideal

Claro, es una decisión importante y tiene sentido pensarlo. Solo para ayudarte bien, ¿lo que te gustaría pensar es el precio, la cobertura, el plazo o si realmente lo necesitas? Te lo pregunto porque si es información, lo resolvemos ahora. Y si la cobertura hace sentido, lo mejor es no dejar protección importante para después.

# Pregunta De Control

¿Hay algo específico de la cobertura o del precio que te preocupe?

# Cierre Sugerido

Si la duda es información, resolvámosla ahora. Si la cobertura hace sentido, dejémosla activa hoy.

# Marco Legal Para Ventas Sanas

# Condiciones Generales

# Qué Son

Las condiciones generales son el marco global de la póliza.

Definen estructura, funcionamiento, obligaciones, exclusiones generales y criterios principales.

# Cómo Explicarlo

Estas son las reglas generales del seguro. Funcionan como la base del contrato.

# Condiciones Particulares

# Qué Son

Las condiciones particulares contienen los datos específicos del cliente.

Incluyen datos del asegurado, plan contratado, sumas aseguradas y condiciones específicas.

# Cómo Explicarlo

Aquí está tu información concreta como asegurado, el plan que estás tomando y las sumas correspondientes.

# Condiciones Especiales

# Qué Son

Las condiciones especiales pueden complementar, modificar o precisar condiciones anteriores.

Cuando aplican, pueden prevalecer sobre otras reglas.

# Cómo Explicarlo

Estas condiciones ajustan puntos específicos del contrato. Por eso siempre es importante revisarlas.

# Derecho De Arrepentimiento

# Qué Es

El cliente tiene 15 días calendario para cancelar sin penalidad.

# Cómo Explicarlo

Además, cuentas con derecho de arrepentimiento. Tienes 15 días calendario para cancelar sin penalidad. Esto te permite tomar la decisión con tranquilidad y transparencia.

# Preexistencias Día 0

# Qué Son

Las preexistencias son condiciones que ya existían antes de contratar el seguro.

# Cómo Explicarlo

El seguro protege riesgos futuros según condiciones. Por eso es importante contratar antes de que aparezca un diagnóstico o una condición médica.

# Periodo De Carencia

# Qué Es

Es un tiempo inicial donde ciertas enfermedades nuevas todavía no se cubren.

Ejemplo de referencia: 30 días.

# Cómo Explicarlo

La carencia es un periodo inicial. Durante ese tiempo, ciertas enfermedades nuevas todavía no se cubren. Explicarlo desde el inicio genera confianza.

# Periodo De Espera

# Qué Es

Es un tiempo específico para que ciertas coberturas se activen.

Ejemplo de referencia: 10 meses para maternidad.

# Cómo Explicarlo

Algunas coberturas tienen tiempos específicos antes de activarse. No todos los beneficios comienzan en el mismo momento. Lo importante es que lo tengas claro desde el primer día.

# Regla Comercial Legal

Explicar carencia y espera no asusta al cliente.

Genera confianza.

Reduce reclamos.

Aumenta transparencia.

Protege la relación comercial.

# Errores Comunes Del Vendedor

# Error 1 Vender Producto Sin Diagnosticar

El vendedor presenta opciones sin entender necesidad real.

Esto genera confusión, objeción de precio y baja conversión.

# Error 2 Hablar Solo De Precio

Cuando el vendedor habla de precio antes de valor, convierte el seguro en gasto.

Primero se debe hablar de riesgo, consecuencia y protección.

# Error 3 No Saber Explicar Los Números

El vendedor debe dominar montos, límites, días, porcentajes, edades, copagos y plazos.

Si no domina los números, pierde autoridad.

# Error 4 No Manejar Objeciones

Responder con presión destruye confianza.

Responder con validación y preguntas recupera control.

# Error 5 No Explicar Condiciones Legales

No explicar carencias, esperas o preexistencias puede generar reclamos.

La transparencia aumenta fidelidad.
