# PRODUCTO MULTISALUD BASE - TABLA DE BENEFICIOS - PACÍFICO / SAGA FALABELLA

## QUÉ ES
Seguro de salud de alta cobertura con respaldo financiero fuerte (hasta S/2,000,000 anual). Diseñado para eventos grandes + uso constante.

## DIFERENCIADOR CLAVE
Duplica la cobertura de Salud Esencial: S/2,000,000 vs S/1,000,000.

## IMPACTO REAL
Un cáncer o cirugía compleja puede costar S/50,000 a S/1,000,000. Este seguro lo absorbe.

## CÓMO FUNCIONA
Modalidad: pago a crédito en red afiliada
- No hay reembolso
- Solo Perú

## PERFIL DE CLIENTE
- Edad: hasta 60 años ingreso
- Permanencia: sin límite
- Familias
- Personas con ingresos medios-altos
- Clientes que buscan protección real

## COBERTURA PRINCIPAL
S/2,000,000 anual

Puede cubrir múltiples cirugías, tratamientos largos, enfermedades graves.

## ATENCIÓN AMBULATORIA

### Deducibles por red:
- Red 1: S/30
- Red 2: S/40
- Red 3: S/60
- Red 4: S/85
- Red 5: S/100

### Coaseguro: 10% a 40%

Ejemplo: consulta S/200, cliente paga desde S/50 a S/120.

### Copago máximo por red:
- Red 1: S/3,000
- Red 2: S/4,500

Ejemplo: hospitalización S/50,000, cliente paga máximo S/3,000.
